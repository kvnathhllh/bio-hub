## 🇮🇩 Bahasa Indonesia

### ✨ Fitur Utama
* 🎨 **Glassmorphism & UI Modern:** Tampilan semi-transparan elegan dengan efek *backdrop blur* dan skema warna gelap (*dark mode*) estetik.
* 🎵 **Pemutar Musik Multi-Track:** Tombol kontrol audio dan menu pilihan lagu interaktif yang bisa diganti pengunjung secara langsung.
* 🎬 **Latar Belakang Video Sinematik:** Background video dinamis dengan transisi efek *TV-overlay* halus saat musik diaktifkan.
* 🌠 **Efek Kosmik Realistis:** Animasi bintang berkelip (*twinkling stars*), debu kosmik melayang, dan efek hujan meteor (*shooting stars*) otomatis.
* 💿 **Animasi Piringan Hitam:** Foto profil otomatis berputar saat musik dimainkan.
* 📱 **Responsif:** Tampil sempurna di semua ukuran layar (perangkat seluler & desktop).
* 🔓 **100% Bebas Watermark:** Bebas digunakan, disalin, dikembangkan, atau dimodifikasi sesuka hati tanpa batasan hak cipta/watermark.

### 🚀 Cara Penggunaan
1. **Clone atau Unduh Repository:**
<pre><code>git clone [https://github.com/kvnathhllh/link-in-bio.git](https://github.com/kvnathhllh/link-in-bio.git)</code></pre>
2. **Edit Berkas `index.html`:**
   * Buka file `index.html` menggunakan teks editor (seperti VS Code).
3. **Ubah Informasi Pribadi:**
   * Sesuaikan nama, bio, serta tautan media sosial pada elemen HTML.
   * Ganti tautan gambar profil, file audio, dan video dengan aset milikmu sendiri.
4. **Deploy Ke Web:**
   * Unggah berkas ke GitHub Pages, Vercel, Netlify, atau layanan hosting pilihanmu secara gratis.

### 🛠️ Kustomisasi
* **Mengganti Musik & Video:** Cari tag `<audio>` dan `<video>` pada file `index.html` lalu ubah atribut `src` sesuai file media milikmu.
* **Mengubah Tautan Media Sosial:** Cari bagian dengan class `.links-list` pada berkas HTML dan sesuaikan atribut `href` dengan tautan akunmu.

## 🇬🇧 English Version

### ✨ Key Features
* 🎨 **Glassmorphism & Modern UI:** Elegant semi-transparent layout featuring backdrop blur effects and a sleek dark-mode aesthetic.
* 🎵 **Multi-Track Music Player:** Interactive audio controls and track selection menu allowing visitors to switch background music seamlessly.
* 🎬 **Cinematic Video Backgrounds:** Dynamic looping background videos equipped with smooth TV-switch overlay transitions.
* 🌠 **Realistic Cosmic Animations:** Automatically generated twinkling stars, floating cosmic dust, and dynamic shooting stars (meteors).
* 💿 **Vinyl Profile Animation:** Profile picture spins like a vinyl record when audio plays.
* 📱 **Fully Responsive:** Optimized to look flawless and perform smoothly across both mobile and desktop screens.
* 🔓 **100% Free & Open Source:** Free to use, fork, modify, and adapt however you like with zero watermark restrictions.

### 🚀 Installation & Setup
1. **Clone or Download the Repository:**
<pre><code>git clone [https://github.com/kvnathhllh/link-in-bio.git](https://github.com/kvnathhllh/link-in-bio.git)</code></pre>
2. **Open `index.html`:**
   * Open the `index.html` file using your favorite code editor (e.g., VS Code).
3. **Update Your Details:**
   * Modify your name, bio, and social media links inside the HTML markup.
   * Replace profile images, audio links, and video URLs with your own assets.
4. **Deploy:**
   * Host your files for free using GitHub Pages, Vercel, Netlify, or any static hosting provider.

### 🛠️ Customization
* **Changing Music & Videos:** Locate the `<audio>` and `<video>` tags in `index.html` and update the `src` attributes with your custom media links.
* **Updating Social Links:** Find the `.links-list` section in the HTML file and update the `href` attributes with your respective profile links.
